## Too many pokemon available
Problem: there are too many event pokemon available to search and visit, each with it's own dex number too. For example, there are several pikachus: rock start, belle, pop star, phd, libre, cosplaty, original hat. The only difference between these and a normal pikachu is the sprite, the stats are all the same. This happens with totem pokemon too, but with no difference to the sprite nor stats, just the name and dex. 

Suggestion: treat pokemon with the same name but different entries as variants of the original. so pikachu rock star = pikachu. In the pokemon lookup UI, add a drop down above the sprite image to select and view these variants. selecting it updates the sprite image and any other data that changes, but the dex number is still the parent pokemon's. remove these variants from search / have them point to the parent pokemon. 

Status: resolved
